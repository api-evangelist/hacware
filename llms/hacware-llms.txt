# HacWare Security Awareness API

> HacWare is an AI-powered security awareness training and phishing simulation platform. Its RESTful Security Awareness API lets partners embed HacWare: AI-generated phishing simulations (clickable link, attachment, direct response, SMS), micro-training courses, lesson plans and quizzes, dark web breach reporting, human-factor risk assessment, user/group and Microsoft 365 group management, a multi-tenant partner/customer hierarchy, and compliance evidence retrieval. Authenticate by exchanging an application id and secret key at POST /api/v1/auth/ to obtain a bearer access token (~1h TTL). HacWare is a Techstars portfolio company.
